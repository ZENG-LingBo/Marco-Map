Marco-Map · prototype · September 2026

Reading historical maps: a demonstration

Two maps served straight from library image servers, shown with the features Prof. Caboara asked about: deep zoom, numbered annotations that open the original inscription beside its translation and commentary, a switch between the front and back of the sheet, a guided tour, and a narrative mode. Everything here is plain HTML and one JSON file per map.

Notes

Transcriptions and translations are illustrative and were prepared for this prototype; they must be checked before publication. Images: Library of Congress, Geography and Map Division, and the World Digital Library collection (original of the Miller Atlas at the Bibliothèque nationale de France), all free to use and reuse.

The pages need to be served over HTTP (for example python3 -m http.server in this folder, or GitHub Pages); they load the map data with fetch.
